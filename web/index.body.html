FuguBench

FuguBench outfits a FuguBSD checkout for a coding agent. It installs the dependencies that a repository names, and it makes and removes the worktrees of a workspace. It operates the learning library, answers the Claude Code hooks, and measures the sessions.

One packed Perl file holds every verb. It runs on core Perl v5.34, and it loads no CPAN module. fugubench shim prints a wrapper shim that pins one release. The shim downloads that release once, holds it to a digest, and caches it.

The program builds on the Fugu library, and the pack carries the Fugu modules that it uses.

Installation

The install script downloads the latest release, holds it to a digest, and copies the program into ~/.local/bin:

curl -fsSL https://bench.fugubsd.org/get | sh

Then fugubench update replaces the program with a later release.
