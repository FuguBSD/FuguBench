# Decisions

This document holds the decisions that govern FuguBench. A plan must not go
against a decision. To change a decision, propose the change and get human
approval first.

| ID   | Decision                                                                                                                                                                                  | Rationale                                                                                                                                              |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| D-01 | FuguBench is one program with subcommands, and the files that it reads are the contract: `deps/<OS>.txt`, `deps/SHA256.txt`, `deps/KEYS.txt`, `.toolingrc`, and the pages of the library. | Eleven repositories hold those files today. The program changes, and no consumer file changes.                                                         |
| D-02 | The program is Perl on core modules and v5.34, built on the Fugu library. The pack carries a snapshot of the Fugu modules that the program uses.                                          | One toolchain serves the organization. macOS ships perl 5.34 in base. A snapshot needs no installed Fugu, so the bootstrap can use the library.        |
| D-03 | The release ships one packed file for every platform, and one CPAN tarball for cpanm and PAUSE.                                                                                           | One file takes one URL, one digest, and one signature. A native binary would take six of each.                                                         |
| D-04 | A consumer runs the program through a synced wrapper shim, and the shim pins the release. No install step precedes `make deps`.                                                           | The program that installs programs must be present before the first install. The shim fetches and verifies the pinned release, so a fresh clone works. |
| D-05 | The first fetch of the shim trusts HTTPS to GitHub. Every later download verifies against the release key of the organization, in-process.                                                | This is the trust root of rustup and Homebrew. In-process verification needs no signify(1) on the host.                                                |
| D-06 | No verb removes a worktree without an operator.                                                                                                                                           | A session captures its work in the clones inside its worktree, and an automatic removal destroys that work. Workspace D-06 holds the same decision.    |
| D-07 | The program reads each hook payload itself, and no hook command needs `jq`.                                                                                                               | One dependency less on the host, and one line for each hook in the settings file.                                                                      |
| D-08 | A session page keeps the name `Session-<project>-<date>-<n>`. The program fetches the origin before it picks `n`, and it renames the page on a collision.                                 | The library holds its pages in that scheme. The race sits in the program, not in the scheme.                                                           |
| D-09 | FuguBench holds the design of the dependency installer. When the port lands, the org pack of Tooling ships the shim in place of `scripts/deps` and `scripts/ftp`, in a plan of Tooling.   | One fact lives in one place. Tooling owns the pack, so Tooling lands the swap.                                                                         |
| D-10 | The Claude Code assumptions live in the hook verb and the trace verb only. Every other verb is agent-agnostic.                                                                            | The harness changes faster than git does.                                                                                                              |
