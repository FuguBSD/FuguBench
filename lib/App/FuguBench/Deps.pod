=head1 NAME

App::FuguBench::Deps - the deps verb of fugubench

=head1 SYNOPSIS

    fugubench [-C <dir>] deps --dry-run [--os <name>] [--arch <name>] <environment>

=head1 DESCRIPTION

B<App::FuguBench::Deps> holds the C<deps> verb. The verb reads the
external dependencies that F<< deps/<OS>.txt >> names, and it prints
the command of each one. The environments are C<tool>, C<runtime>,
C<test>, and C<develop>, and the verb takes one of them as its
argument.

The design comes from the synced F<scripts/deps> of Tooling. The
trace of C<--dry-run> equals the trace of that script, line for line,
over the manifest of every consumer. The test
F<t/fugubench/deps-conformance.t> holds that comparison, and no
consumer file changes.

The install of an entry needs the downloader, the digest check, and
the installers. This distribution holds none of them, so the verb
takes C<--dry-run> alone. A run without the option reports the absent
install and returns 1.

=head2 command

C<command($verb)> returns the entry of the L<Fugu::CLI> table. The
module holds one verb, so it ignores the name.

=head2 THE START DIRECTORY

The verb reads F<< deps/<OS>.txt >> relative to the start directory,
which C<-C> names, and it walks up to no checkout. A guest runs
C<make deps> out of an extracted tarball, and that tree holds no
F<.toolingrc>. The verb reads no path relative to the program.

C<--os> and C<--arch> replace the two words of uname(3). Each word
becomes part of a file name, so each one holds letters, digits, a
dot, a dash, and an underscore, and each one starts with a letter or
a digit. Every other word is a usage error.

=head2 THE MANIFEST

A line of the manifest holds an environment, a type, and a name, with
whitespace between them. The types are C<pkg>, C<dist>, C<cpan>, and
C<bin>. A C<#> at the start of the first word starts a comment.

The verb validates every line before the first command, and not the
lines of the wanted environment alone. A malformed line of another
environment would otherwise stay invisible until someone installs
that environment. An unknown environment, an unknown type, and a line
of fewer than three words are each an error that names the line.

A C<dist> name is one URL. A C<bin> name holds the command name, the
URL, and, for an archive, the path of the file in the archive. An
archive URL ends in F<.tar.gz>, F<.tgz>, or F<.zip>, and it needs the
path. A plain URL takes none. A C<pkg> name and a C<cpan> name reach
a package manager, so neither starts with a dash, and neither is a
URL.

A download URL names a file, and it holds no parenthesis and no
space, which the line format of F<deps/SHA256.txt> reserves. A
command name becomes a file name in the install directory, and an
archive path becomes one in a temporary directory. tar and unzip read
a leading dash as an option, so neither name starts with one, and an
archive path holds no empty and no parent segment.

Without a manifest for the system name, the verb reports that fact
and returns 0.

=head2 THE PLATFORM ALIASES

A release asset spells one platform in more than one way. A manifest
writes C<{os}> and C<{arch}> in place of a platform word, and the
verb expands both, in the URL and in the archive path.

The verb holds one alias table for each word, in preference order.
Darwin gives C<darwin>, C<macOS>, and C<osx>. Linux gives C<linux>,
and OpenBSD gives C<openbsd>. C<x86_64> and C<amd64> give C<amd64>,
C<x64>, and C<x86_64>. C<aarch64> and C<arm64> give C<arm64> and
C<aarch64>. An unknown word gives itself, and an unknown system name
gives its own lower case.

The verb forms one candidate for each alias pair, and it takes the
candidate that F<deps/SHA256.txt> records. No match and more than one
match are each an error that names the repair, and neither one asks
the network. Each placeholder of the archive path must also sit in
the URL, because only the URL selects the platform.

=head2 THE DIGEST FILE

F<deps/SHA256.txt> records a sha256 digest for each download with a
versioned name, and the key is the whole download URL. The verb reads
the file through the manifest reader of L<Fugu::Signify>, which
rejects a bad line, a digest that is not 64 hexadecimal characters,
and a duplicate key. A silent skip would drop a check.

An absent file, and a file with no line, each give the empty set.

=head2 THE TRACE

C<--dry-run> prints each command that the verb would run, as one line
that starts with C<+ > and holds each argument shell-quoted. It runs
none of them. A word passes bare when it holds word characters, a
dot, a solidus, a colon, an equals sign, and a dash alone. Every
other word, and the empty word, takes single quotes.

The program gives no word to a shell. The quoting lets a reader of
the trace see that an argument with a space is one argument.

The trace is the standard output. Every progress line goes to the
logger, which writes to standard error.

The verb downloads in-process, so the trace names the fetch verb:
C<< fugubench fetch <file> <url> >>. Each download takes a temporary
directory of its own, because the signed manifest of a release lands
beside it.

=head2 THE COMMANDS OF ONE ENVIRONMENT

The verb takes the entries of one environment in the order C<pkg>,
C<dist>, C<cpan>, C<bin>. A package can give the toolchain that a
dist build needs, and a dist can give a module that the cpan list
builds on. A binary depends on nothing here. Each command below
reaches the trace, and the install of it is absent.

The trace of a C<pkg> entry names the package manager of the
platform: C<pkg_add> on OpenBSD, C<apt-get install -y> under C<sudo>
on Linux, and C<brew install> on Darwin. On Linux an C<apt-get
update> comes first, and every package of the environment reaches one
command. A system name with no package manager is an error.

The trace of a C<cpan> entry and of a C<dist> entry names
C<cpanm --notest>. With C<PERL_LOCAL_LIB_ROOT> in the environment,
the command takes C<--local-lib> with that value. The C<cpanm> on
PATH is the first choice, and the bare name keeps the trace readable.
Without one, the trace names the download of the standalone C<cpanm>
script into a temporary directory, and this perl runs that script.

The trace of a C<bin> entry names the install into F<~/.local/bin>,
with mode 755. The verb stops with an error when C<HOME> is unset,
before it names one command. For an archive, the trace names tar or
unzip over the one file of the entry, and the copy of that file
alone.

=head1 RETURN VALUES

C<command> returns a hash reference. Its body returns 0 after the
trace, and 0 for a system name that the checkout holds no manifest
for. A usage error returns 2: an unknown environment word, no
environment word, more than one, and a bad C<--os> or C<--arch> word.

A fault of a consumer file returns 3: a bad manifest line, a bad line
of the digest file, and an alias expansion that reaches no candidate
or more than one. An unset C<HOME>, a system name with no package
manager, and a run without C<--dry-run> each return 1.

=head1 FILES

=over 4

=item F<< deps/<OS>.txt >>

The manifest of one system name, relative to the start directory.

=item F<deps/SHA256.txt>

The recorded digest of each download, keyed on the download URL.

=back
